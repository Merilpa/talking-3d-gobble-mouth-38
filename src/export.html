Robot Parlante 3D - Demo

Questo esempio mostra come integrare e controllare il robot parlante 3D sul tuo sito web.

Controlli del robot

Istruzioni per l'integrazione

Per integrare questo robot sul tuo sito web, segui questi passaggi:

  1. Carica la cartella robot-assets sul tuo server web
  2. Aggiungi i riferimenti ai file CSS e JavaScript nel tuo HTML
  3. Crea un elemento contenitore con un ID
  4. Inizializza il robot con window.InitTalkingRobot('id-del-contenitore')

Esempio di codice

<!-- Nel tag <head> -->
<link rel="stylesheet" href="robot-assets/talking-robot.css">

<!-- Nel corpo della pagina -->
<div id="robot-container" style="width: 100%; height: 500px;"></div>

<!-- Prima del tag </body> di chiusura -->
<script src="robot-assets/talking-robot.umd.js"></script>
<script>
  document.addEventListener('DOMContentLoaded', function() {
    // Inizializza il robot
    const robotApi = window.InitTalkingRobot('robot-container');
    
    // Esempio: fai parlare il robot
    // robotApi.speak('Ciao mondo!', 'it-IT');
  });
</script>
